# JobTracker

JobTracker is a job application tracking system built as a practical Java / Jakarta EE / WildFly / PostgreSQL project.

The application is intended to manage the full recruitment process, including:

- companies and job offers
- job application sources
- recruiters and contacts
- recruitment stages and status history
- interviews and meetings
- required and preferred technologies
- salary expectations and proposals
- documents sent during recruitment
- notes and follow-up activities
- recruitment statistics and reports

## Planned architecture

- Java 21
- Jakarta EE
- WildFly
- PostgreSQL
- Maven
- REST API
- JPA / Hibernate
- Ansible deployment
- Nagios monitoring
- CI/CD

## Development model

Application development and builds are performed locally.

Runtime environment:

- WildFly: OCI
- PostgreSQL: OCI
- Monitoring: Nagios on OCI
- Deployment: Ansible
